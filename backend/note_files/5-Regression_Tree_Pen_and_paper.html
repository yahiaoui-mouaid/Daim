1) ما الذي نحاول أن نبنيه؟

Classification Decision Tree هي Model تتعلم سلسلة من الأسئلة، بحيث تقسم البيانات تدريجيًا إلى مجموعات أكثر "نقاءً"، إلى أن نصل إلى Leaf تُعطي Class Prediction.

Root

أول سؤال في الشجرة. يجب أن يكون Split مفيدًا في فصل Classes.

Internal Node

سؤال جديد يظهر بعد تقسيم البيانات.

Leaf

نقطة النهاية التي تنتج Prediction مثل Yes أو No.

3) قبل الحساب: ما معنى "نقاء" المجموعة؟

مجموعة نقية

إذا كانت كل العناصر في المجموعة تنتمي إلى نفس Class، فالمجموعة نقية جدًا.

Yes, Yes, Yes, Yes
Gini = 0

مجموعة مختلطة

إذا كانت Classes مختلطة، نحتاج إلى Split أفضل لفصلها.

Yes, Yes, No, No
Gini = 0.5
لماذا نحتاج Metric مثل Gini؟

لأن الشجرة لا تستطيع أن "تشعر" أن Split جيد أو سيئ. نحتاج رقمًا نقارن به جودة Splits المختلفة.

Gini Impurity يعطي رقمًا يخبرنا بمدى اختلاط الـ Classes داخل المجموعة.

4) نحسب Gini Impurity بالقلم والورقة

Gini = 1 - Σ(pᵢ²)

حيث pᵢ هي نسبة كل Class داخل المجموعة.

مثال 1

المجموعة:

Yes, Yes, Yes

p(Yes)=1
Gini = 1 - 1² = 0

مثال 2

المجموعة:

Yes, No

p(Yes)=0.5
p(No)=0.5
Gini = 1 - (0.5²+0.5²)=0.5

المعنى

كلما اقترب Gini من 0 أصبحت المجموعة أكثر نقاءً.

5) نحسب Gini للـ Root

في البيانات كلها لدينا: 4 Yes و 4 No.

p(Yes)=4/8=0.5
p(No)=4/8=0.5

Gini(root)=1-(0.5²+0.5²)=0.5
إذن: المجموعة الأصلية مختلطة بالكامل تقريبًا. نحتاج الآن إلى أفضل Split.

6) نجرب Feature الأولى: Outlook

Split: Outlook

Sunny

No, No, Yes → 1 Yes, 2 No

Gini(Sunny)=1-[(1/3)²+(2/3)²]
= 1-(1/9+4/9)
= 4/9 ≈ 0.444

Overcast

Yes, Yes → Pure

Gini(Overcast)=0

Rain

Yes, No, No → 1 Yes, 2 No

Gini(Rain)=4/9 ≈ 0.444

الـ Weighted Gini

Weighted Gini = (3/8 × 0.444) + (2/8 × 0) + (3/8 × 0.444)

≈ 0.333
Gain تقريبي: 0.5 - 0.333 = 0.167

7) نقارن ذلك مع Features الأخرى

Feature Weighted Gini تحسن بالنسبة لـ Root
Outlook ≈ 0.333 ≈ 0.167
Humidity ≈ 0.375 ≈ 0.125
Windy ≈ 0.467 ≈ 0.033
لذلك نختار Outlook كأول Split لأن له أقل Weighted Gini وأكبر تحسن في نقاء البيانات.

9) لماذا لا نتوقف عند أول Split؟

لأن كل فرع أصبح Dataset صغيرة جديدة

هذه نقطة مهمة جدًا لفهم الشجرة. بعد Split لا نرمي المشكلة كاملة ونبدأ من الصفر. بل نأخذ كل فرع وكأنه مشكلة تصنيف أصغر.

نعيد حساب Impurity ونبحث عن أفضل Feature أو Threshold للفرع نفسه.

متى نتحول إلى Leaf؟

يمكن أن نتوقف عندما:

  • تصبح المجموعة Pure.
  • لا توجد Features مفيدة إضافية.
  • نصل إلى حد أقصى للعمق مثل max_depth.
  • يصبح عدد العينات صغيرًا جدًا حسب قواعد النموذج.

10) ماذا يحدث داخل Model جاهز؟

1. Generate Candidate Splits

يجرب النموذج Features وValues أو Categories مرشحة للتقسيم.

2. Measure Quality

يحسب معيارًا مثل Gini أو Entropy.

3. Choose Best Split

يختار التقسيم الذي يحقق أفضل تحسن وفق المعيار المستخدم.

Gini أم Entropy؟

كلاهما يستخدم لقياس عدم النقاء، لكن بطريقة حساب مختلفة.

Gini = 1 - Σ(pᵢ²)
Entropy = -Σ(pᵢ log₂ pᵢ)

المهم في مرحلة التعلم ليس حفظ الصيغة فقط، بل فهم الفكرة: النموذج يبحث عن Split يجعل الفروع أكثر نقاءً.

11) من الورقة إلى Code

فكّر في العملية التالية قبل أن تفكر في syntax:

DATA
↓
FIND CANDIDATE SPLITS
↓
CALCULATE IMPURITY FOR EACH SPLIT
↓
CHOOSE BEST SPLIT
↓
CREATE NODE
↓
REPEAT FOR EACH CHILD
↓
STOP → LEAF / PREDICTION
هذه هي الفكرة التي تريد أن تراها في رأسك عندما تقرأ implementation داخليًا لـ Decision Tree.

12) تحدي بالقلم والورقة

لا تستخدم Calculator في البداية

اكتب بنفسك:

  1. عدد Yes و No في Root.
  2. Gini للـ Root.
  3. Gini لكل مجموعة ناتجة عن Outlook.
  4. Weighted Gini للـ Outlook.
  5. قارن النتيجة مع Humidity.
  6. قرر أي Feature تستحق أن تكون Root.

13) الخلاصة الذهنية

Decision Tree ≈ "ما هو أفضل سؤال يمكنني طرحه الآن لكي أقسم البيانات إلى مجموعات أكثر نقاءً؟"

ثم نكرر السؤال نفسه على الفروع الجديدة.

هذه هي الصورة الداخلية التي ينبغي أن تفهمها قبل استخدام: DecisionTreeClassifier.
